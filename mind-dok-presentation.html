App Introduction

Mind Dok

AI document assistant — scan, understand, and never miss a deadline.

Presented for end-user onboarding · Danish digital documents · Android

Why Mind Dok exists

The problem for Danish citizens

Important documents arrive digitally every week — but deadlines still get missed.

📄

Scattered

Letters live in mit.dk, e-Boks, email, and apps — nowhere together.

⏰

Missed deadlines

Payment due dates, tax deadlines, and appointments slip through the cracks.

🔍

Hard to read

Official letters are dense. Finding the one action that matters takes time.

The solution

One app that reads your documents — and tells you what to do

Mind Dok turns your paper and digital documents into an organised, searchable library, then automatically creates reminders for every deadline, appointment, and due date it finds.

📥 Import anything

PDFs, photos, scans, Word, Excel — via share menu, printer, or camera.

🤖 AI analysis

Identifies type, amounts, organisations, and dates as tappable key-fact chips.

⏰ Auto reminders

Reminders created automatically with the right lead time based on urgency.

📅 Calendar sync

Appointments add to the device calendar with one tap.

The flow

How it works — in 5 simple steps

1

Share

Open a document and share it to Mind Dok (or print to it).

2

Capture

Mind Dok stores the file securely on the device.

3

OCR

On-device text recognition extracts the content.

4

Analyse

Deadlines, amounts, and organisations are identified.

5

Remind

Reminders and calendar events are created automatically.

Feature highlights

What makes Mind Dok special

  • Import PDF, JPG, PNG, DOCX, XLSX, TXT and more
  • Camera document scanner with edge detection
  • On-device OCR — Google ML Kit, no internet needed
  • Optional AI analysis via Mistral (bring your own key)
  • Automatic reminders with priority levels (low → urgent)
  • Calendar event creation from appointment documents
  • Biometric app lock (fingerprint / face)
  • Danish and English interface

Document coverage

Built for the documents Danes actually receive

Fakturaer · Invoices Skat · Tax Sundhed · Healthcare Forsikring · Insurance Kommune · Municipality Pension Kontrakter · Contracts Aftaler · Appointments

Each document is automatically sorted into the right category so users always know where to find it.

Trust & security

Fully private — documents never leave the device

🔒 Local storage

All documents and reminders are stored on-device. No account required.

🚫 No tracking

No ads, no analytics, no cloud sync by Mind Dok itself.

📶 Offline OCR

Text recognition runs on-device with Google ML Kit.

🔐 Biometric lock

Optional fingerprint / face unlock keeps documents secure.

About AI analysis

AI analysis is optional. If enabled, only the extracted text (never the file) is sent to Mistral's API over an encrypted connection — using the user's own API key.
