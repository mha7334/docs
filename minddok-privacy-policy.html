Mind Dok – Privacy Policy

Last updated: 13 June 2026

Mind Dok is a document assistant app developed by Muhammad Asif, Aarhus, Denmark (package: dk.masif.minddok). This policy explains what data the app processes and how it is handled.

What Mind Dok Does

Mind Dok lets you import documents (PDFs, images, scanned pages) to your device, extract text using on-device OCR, and optionally analyse the text with an AI service to identify key facts, deadlines, and reminders. All document storage and reminders are local to your device.

Data Stored on Your Device

The following data is stored locally in an encrypted SQLite database and never uploaded to any server by Mind Dok itself:

  • Imported document files (copies stored in the app's private storage)
  • OCR-extracted text from those documents
  • Reminders and calendar events derived from document content
  • App settings including your preferred language

AI Analysis (Optional)

If you choose to enable AI analysis, you provide a personal API key for the Mistral AI service. When AI analysis is triggered for a document, the OCR text of that document is sent to Mistral AI's servers (api.mistral.ai) over an encrypted HTTPS connection for processing. No document files, images, or other personal information are transmitted — only the extracted plain text.

Your API key is stored locally on your device using Android's SharedPreferences and is never transmitted to any server other than Mistral's own API endpoint. Mistral AI's own privacy policy governs how they handle API requests: mistral.ai/privacy.

AI analysis is entirely optional. The app is fully functional without it.

Biometric Authentication (Optional)

Mind Dok can lock itself behind your device's biometric authentication (fingerprint or face unlock). This is handled entirely by Android's BiometricPrompt API. No biometric data is accessed or stored by the app.

Permissions

  • Camera – used only for the in-app document scanner feature
  • Storage / Media – to read files you choose to import
  • Calendar – to add events you explicitly confirm
  • Notifications – to deliver document reminders you set up
  • Biometrics – to lock the app if you enable that feature
  • Internet – used only when AI analysis is enabled (Mistral API)

No permission is used for advertising, tracking, or analytics purposes.

Third-Party Services

Mind Dok does not include any advertising SDKs, analytics libraries, or crash-reporting services. The only optional third-party network call is to the Mistral AI API described above, and only when you have entered an API key and triggered an analysis.

Data Sharing

Mind Dok does not sell, rent, or share your data with any third party, except as described under AI Analysis above (text sent to Mistral when you opt in).

Data Deletion

All data is stored on your device. You can delete individual documents and reminders within the app, or uninstall the app to remove all associated data. No data is retained on any external server by Mind Dok.

Children

Mind Dok is not directed at children under 13. The app does not knowingly collect personal information from children.
